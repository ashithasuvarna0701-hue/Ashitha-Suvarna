## 🎨 Design System & Highlights

- **Visual Palette:** `Orange & Charcoal`
  - Accent Primary: Warm vibrant orange (`#EA580C` / `#FF7A1A` with amber glow)
  - Charcoal Tones: Deep graphite and slate surfaces (`#101215`, `#1B1E24`, `#22262E`)
  - Clean Surfaces: Crisp high-contrast off-white (`#FAF9F6`, `#FFFFFF`)
- **Default Appearance Mode:** Light Theme with instant Dark Theme switcher and `localStorage` persistence.
- **Motion & Accessibility:** Subtle animations respecting `prefers-reduced-motion` media queries.
- **Hero Presentation:** Text-Focused Introduction highlighting MCA status at Poornaprajna Institute of Management (PIM), elevator pitch, location badge, direct connect social strip, and action triggers.
- **Interactive Resume Modal:** Embedded printable stationary paper format with one-click **Print / Save as PDF** and **Download Plaintext (.txt)** actions.
- **Project Filter Tabs:** Dynamic category filtering across Web Development, Databases & Backend, and Data Science.
- **One-Click Clipboard Triggers:** Instant copy for email and telephone with toast notification feedback.

## 🚀 How to Run Locally

Because this project is built using standard web technologies (HTML/CSS/JS) with zero bloated external dependencies or build tools, you can open and run it immediately:

### Option 1: Direct File Open
Simply double-click `index.html` or open it with your browser:
```bash
start index.html
```

### Option 2: Using Python HTTP Server (Recommended)
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your web browser.

### Option 3: Using Node / npx
```bash
npx serve .
```
